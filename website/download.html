Automatic install (with your consent)

When you download on a device, ClassWatch can offer to install automatically — only after you click "Install". Nothing installs silently without consent. Steps:

  1. Download the installer for your OS above.
  2. Open it — Windows will ask for administrator permission (needed to install the background service).
  3. On the components page, uncheck "ClassWatch Master" on student machines (or run setup.exe /NoMaster for silent student installs).
  4. The service starts automatically at every boot — students cannot stop it without the admin password.
